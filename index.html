How I launch a site

The same four steps on every client project, from the first conversation to the hand-over.

  1. Brief

    I agree with the client what the site needs to do and how visitors should reach them: a call, WhatsApp, Instagram or a form.

  2. Build

    Plain HTML, CSS and JavaScript, responsive from phone to desktop, with accessibility basics like visible focus states and reduced motion.

  3. Review

    The client checks the full site at a hidden, no-index URL. A coming-soon page can hold the live domain in the meantime.

  4. Launch and hand over

    I set up the domain and the deploy, add meta tags, canonical URLs, Open Graph and structured data, and write a guide so the client can look after the site.
